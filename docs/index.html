    What the first live run caught (all fixed, with regression tests)

    • False 'vendor-owned' MCP matches. Prefix matching on GitHub org names accepted io.github.Xerolo44 as Xero, io.github.Ramp-Jet as Ramp and io.github.copperline-labs as Copper; a stranger's app.netlify.<user> site passed as Netlify; Binance's github.io docs host made every io.github.* entry look like Binance's. Fixed: exact org match, shared-hosting denylist; vendor matches are now recomputed from raw registry names on every build.
    • robots.txt over-blocking. Python's built-in reader treats a 403 on robots.txt as 'disallow everything', which flagged 30 docs sites (mostly bot protection). Replaced with RFC 9309 behaviour (4xx = no rules, 5xx = disallow); disallowed pages are now not fetched at all.
    • A broken link in the brief. The Neo4j hint neo4j.com/docs/api returns 404; the evidence now points at the docs root.

    Was the agent's own confidence honest?

    Share of pass-1 rows later corrected, by the confidence the agent gave itself. Low-confidence rows were wrong far more often, which justified routing research effort to them first.

    Known limits

    • With 42 holdout fields and no misses, the 95% lower bound on accuracy is about 93%: expect a few residual errors, most likely in the MCP column.
    • 24 official-MCP claims (marked ?) are pass-1 knowledge, not re-read this run.
    • 34 rows cite the docs root from the brief and were not re-read this run; python -m agent links checks they resolve.
    • The Composio catalogue column comes from direct slug-page checks in the live sweep (a summarised read of the catalogue sitemap contradicted the homepage, so it was not used). A missing page can also mean an unusual slug; each match shows its slug.
    • Keyword corroboration only tells you an evidence page mentions the auth method; it is a weak signal, used to queue rows, not to score them.
    • Plan and pricing gates drift; verdicts are as of 23 Nov 2026.

    The agent

    A researcher, a blind verifier and a claim judge per app, run concurrently with caching and retries. Anything they cannot settle goes to a human queue. Replay the recorded run for any app below; with the local server running, you can stream a live run.

    1 · Draft

    Closed-book pass

    All fields from model knowledge plus a self-rated confidence, recorded before any search.

    2 · Discover

    Find vendor docs

    Gemini grounding or Composio Tavily search; vendor domains ranked first.

    3 · Read

    robots-aware fetch

    Disk-cached, retried with backoff; robots.txt blocks go to a human.

    4 · Lookups

    MCP Registry + catalogue

    Deterministic: domain-verified registry namespaces and Composio slug pages.

    5 · Extract

    Schema-locked record

    Pydantic schema; every claim carries a URL and a verbatim quote.

    6 · Verify

    Quote · blind · judge

    Quote must be on the page; a second model re-extracts blind; a judge grades each claim.

    7 · Route

    Final or human

    Disagreement, contradiction, blocked page or low confidence → human queue.

      Live mode needs the local server. Run python -m agent serve and open http://localhost:8787 (add --mock to replay without keys).

      Where a human was needed in this run

      • Agent-blocked sources: systeme.io developer docs disallow bots (robots.txt); fanbasis and PitchBook refused fetches; Ramp's docs need JavaScript.
      • No findable docs: fanbasis, Paygent Connect, iPayX. Recorded as 'no public API docs', not guessed.
      • Rubric calls: what counts as self-serve (one-off credits = trial) and as an official MCP (docs-only does not count). Decided by a human, then encoded in the prompt.
      • Sign-off: 10 items in the human queue; 0 closed.

      Runtime used for this run. The published 100-app run was executed by an LLM agent (Claude, Anthropic) with web search and page fetch, following the protocol and rubric in agent/prompts.py. The repo's runner executes the same protocol on Gemini (optional Composio search tools) with a blind verifier and judge; it was not executed in the build sandbox, which had no outbound network. Its loop is covered by offline tests with a fake model. All ground truth was read from vendor pages. The agent's network tools (MCP Registry, Composio catalogue, link checks, headless-browser reads) were executed live across all 100 apps in GitHub Actions on 2026-11-23 (run log).
